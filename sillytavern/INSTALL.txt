Copy both .patch files into the SillyTavern application directory, then run:

git apply --check sillytavern-stream-debug.patch
git apply sillytavern-stream-debug.patch
git apply --check vertex-text.patch
git apply vertex-text.patch

If the stream-debug patch is already installed, skip its two commands. If a check fails, stop before applying that patch.
Restart SillyTavern and hard-refresh the browser. Open the Google Vertex AI connection settings to configure the new options.
The actual_content option converts an existing tool call into chat text; keep the script or preset that defines that tool.
The diagnostic page is available at /api/stream-debug after signing in.
